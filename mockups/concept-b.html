Ashby Plot Builder · Concept B, iteration 2

Ashby Concept B

Plots and datasets now live in their own strip above the editor, and every setting says who it affects (the whole dataset or only this plot) and whether you need to touch it. Simple mode hides everything that can stay at its default. Clickable mockup with the spritzguss-showcase example; nothing renders or downloads.

Who a setting affects

  • DatasetShared. Saved once per dataframe and used by every plot in it: data source, axis definitions, material colors, legend title, fonts, dark mode, image output.
  • PlotOnly this plot (frame): X/Y quantities, scale, range, title, hulls, areas, guidelines, annotations.
  • ProjectThe config file with all datasets: import, export, JSON, reset.

Whether you need to change it

  • RequiredMust be set or the plot cannot render. Turns green when done, orange when missing.
  • CheckWorks as is, but you usually want to review it: titles, labels, scale, colors.
  • Default OKGives a good result untouched. Hidden in Simple mode; a counter shows how many and whether any were changed.
