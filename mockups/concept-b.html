Ashby Plot Builder · Concept B, iteration 3

Ashby Concept B

Slim plot tabs, small status icons, one language at a time, roomier axis definitions and a resizable preview. Clickable mockup with the spritzguss-showcase example; nothing renders or downloads.

Who a setting affects

  • DatasetShared by every plot of the dataframe: data source, languages, axis definitions, material colors, legend title, fonts, dark mode, image output.
  • PlotOnly this plot (frame): title, X/Y, range, hulls, areas, guidelines, annotations.
  • ProjectThe config file with all datasets.

Whether you need to change it (hover the icons)

  • Required. Orange until set, green when done.
  • Check. Works as is, but usually worth a look.
  • Default OK. Hidden in Simple mode. Filled when changed from the default.
